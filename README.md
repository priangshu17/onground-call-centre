# OnGround Call Centre
An agent workspace for the OnGround.AI call-centre assignment. This first slice includes a responsive dashboard, shared navigation, lead queue, and lead profile.
## Run locally
```sh
npm install
npm run dev
```
## Direction
- React + Vite frontend
- A small Node/Express service for secure telephony credentials and provider webhooks
- Local sample data for assignment screens
- A real calling integration will be configured separately, with provider credentials held only on the server
